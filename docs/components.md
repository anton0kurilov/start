# Каталог компонентов

[К оглавлению](README.md). Названия Svelte-компонентов здесь и в
[плане переноса](svelte-migration.md) — предложения. Текущая реализация
использует HTML, CSS-классы и функции из [ui.js](../src/scripts/ui.js).

## Базовые элементы

### Кнопка

Основа — `.btn`: прозрачный фон, граница `1px`, радиус `10px`,
padding `12px 18px`, текст `0.95rem / 600`.

| Вариант | Классы | Применение |
| --- | --- | --- |
| Primary | `btn btn--primary` | Создать, подписаться, сохранить, импорт/экспорт, вход в настройки |
| Ghost | `btn btn--ghost` | Отмена, редактирование, дополнительные действия |
| Danger | `btn btn--danger` | Удаление и сброс |
| Compact | `btn btn--compact` | Определён в SCSS: `6px 10px`, `0.75rem`, min-height `30px`; текущая разметка его не использует |

Disabled задаётся нативным `disabled`: opacity `0.6`,
cursor `not-allowed`, без transform и box-shadow.

Иконки-кнопки — локальные варианты `.fab__icon-btn`,
`.settings__icon-btn`, `.columns__mark-read` и другие.
Самостоятельного общего CSS-класса `.icon-btn` сейчас нет.
У кнопки без видимого текста есть `aria-label`, обычно и `title`;
SVG имеет `aria-hidden="true"` и `focusable="false"`.

Контракт переноса: сохранить семантический `button`, явный `type`,
disabled, доступное название и состояние `aria-pressed/expanded`.
Не заменять интерактивные кнопки кликабельными `div`.

### Поле, textarea и форма

`.control`: ширина `100%`, padding `10px 12px`, радиус `12px`,
фон surface. В настройках размер текста `1rem` и единая минимальная
высота. `.form` — grid с gap `12px`; label — `.form__field`.

| Элемент | Текущее устройство |
| --- | --- |
| Название колонки/подписки | Text input, обязательное значение |
| Новый RSS URL | `type="url"`, required, описание ошибки через `aria-describedby` |
| Редактирование RSS URL | `type="text"`, `inputMode="url"`, отдельное доступное название |
| Обычная textarea | min-height `120px`, resize vertical |
| Фильтр | `rows="8"`, min-height `180px`, line-height `1.5`, spellcheck выключен |
| Выбор JSON | Скрытый native file input, открываемый отдельной кнопкой |

Ошибка добавления подписки — красный абзац `role="alert"`.
Невалидному URL задаётся `aria-invalid="true"`, фокус возвращается
в поле. Ввод очищает ошибку.

### Option с checkbox

`.settings__option` — вся строка является label: checkbox слева,
заголовок и необязательное пояснение справа. Строка имеет радиус
`12px`, gap `14px`, padding `12px 14px`.

Checkbox кастомный, `18px`, галочка рисуется CSS. Состояния:
unchecked, checked, disabled, focus-visible. В `forced-colors`
возвращается нативный appearance.

Три существующие опции: автоматическая прочитанность при прокрутке,
автообновление и показ рекомендуемой колонки.

### Обратная связь

| Компонент | Назначение | Жизненный цикл |
| --- | --- | --- |
| `.fab__toast` | Нет сети / все источники не обновились | Явное закрытие, новое обновление или событие online; таймера автозакрытия нет |
| `.columns__notice` | Ошибки конкретных подписок при наличии карточек | Можно закрыть; запоминается текущая комбинация ошибок в памяти |
| `.settings__form-error` | Проверка новой подписки не прошла | Исчезает при вводе или новом открытии формы |
| `.settings__reorder-status` | Результат перестановки колонок | Обычно скрыт визуально, объявляется через `role="status"`; ошибка становится видимой |
| `.columns__empty` | Нет колонок, подписок или публикаций | Заменяет соответствующее содержимое |
| `.settings__empty` | Нет групп подписок | Пунктирная рамка, спокойный текст |

Общего toast-менеджера, skeleton, progress bar, меню уведомлений и
постоянного индикатора offline сейчас нет.

## Экран чтения

### Лента колонок — `.columns`

Горизонтальный контейнер. Порядок обычных колонок совпадает с массивом
папок. Рекомендуемая колонка при включении вставляется первой и не
участвует в пользовательской перестановке папок.

Если папок нет, вместо колонок показывается общий текст:
«Создайте первую колонку и подпишитесь на поток в настройках».
Это текст, без встроенной CTA-кнопки.

### Колонка — `.columns__item`

Состав:

1. Абсолютно позиционированная кнопка новых материалов.
2. Прокручиваемая `.columns__content`.
3. Sticky header внутри content: `h2` и кнопка прочитанности.
4. Пустое состояние либо сообщение об ошибках и карточки.

Ключ обычной колонки — `folder:<id>`, рекомендуемой —
`recommended`. Ключ важен для восстановления скролла после обновления
или смены порядка.

| Состояние | Представление |
| --- | --- |
| Нет подписок | «Добавьте потоки в эту колонку.» |
| Подписки есть, материалов нет | «Здесь пока нет публикаций.» |
| Нет материалов и есть ошибки источников | «Не удалось загрузить публикации. Попробуйте обновить позже.» |
| Материалы есть, часть источников не обновилась | Карточки остаются; над ними закрываемое сообщение с именами источников |
| Всё отображаемое прочитано | Действие header меняется на «Отметить публикации как непрочитанные» |
| Нет карточек | Кнопка прочитанности disabled |
| Пришли непрочитанные материалы выше позиции чтения | «↑ Новые материалы» |

В каждой колонке отображается не более `40` публикаций.
Пагинации и кнопки «Загрузить ещё» нет.

Клик по свободной области header прокручивает к началу. Кнопка
прочитанности выполняет своё действие отдельно и не запускает этот скролл.

### Рекомендуемая колонка

Модификатор `.columns__item--recommended`, название
«✦ Рекомендуемое», зелёное оформление.

Содержимое собирается из всех обычных колонок после применения фильтра
заголовков. Отбирается `tone === 'high'`, причём специально без
повышения оценки только за факт открытия. Сортировка сначала по дате,
затем по модельному score при равной дате. Это не сортировка всех
публикаций по score.

Пустые состояния: «Рекомендуемых публикаций пока нет.» либо
«Добавьте потоки, чтобы собрать рекомендации.»

Избранность источника сама по себе не включает его в рекомендации.
Отдельной дедупликации между папками в этой сборке нет.

### Карточка публикации — `.feed__item`

```text
article.feed__item
├── a.feed__item-link
│   ├── Источник
│   └── Заголовок
└── Строка метаданных
    ├── Относительное время
    └── Индикатор полезности + «Показывать меньше похожих»
```

Ссылкой является только блок источника и заголовка. Метаданные и
действие отрицательной оценки находятся вне ссылки. Внешняя страница
открывается в новой вкладке с `noopener noreferrer`.

Нет изображения, аннотации, текста статьи, счётчика комментариев,
закладки публикации и отдельной кнопки «прочитано».

| Состояние | Представление / поведение |
| --- | --- |
| Обычное | Чёрный фон, тонкая серая граница |
| Hover / focus-within | Фон surface |
| `--visited` | Заголовок accent; сама карточка остаётся |
| Браузерный `:visited` ссылки | Тоже делает заголовок accent, независимо от локальной отметки |
| `--favorite-feed` | Жёлтая граница и подложка |
| В рекомендуемой колонке | Зелёное выделение, даже если источник избранный |
| `--dismissed` | Карточка остаётся, кнопка отрицательной оценки активна |
| Некорректная ссылка | `aria-disabled="true"`, `tabIndex=-1`; открытие и учёт клика отключены |
| Нет источника / заголовка | «Источник» / «Без заголовка» |
| Нет даты | «без даты», без tooltip даты |

После отрицательной оценки обработчик меняет кнопку на месте, без
пересборки ленты. В таком обновлении индикатор полезности может остаться
прежним до следующего рендера. Удаление карточки из рекомендуемой колонки
возможно при последующей пересборке и переоценке.

### Индикатор полезности

`.feed__item-utility` — не кнопка и не отдельный голос «нравится».
Это отображение модельного результата или истории.

| Состояние | Видимое содержимое |
| --- | --- |
| `learning` | Серый текст «обучается», без иконки |
| `high / medium / low` с процентом в model label | Только иконка thumbs-up соответствующего цвета |
| `посетил` | Зелёная иконка глаза |
| `скрыл` | Красный индикатор с иконкой и текстом «скрыл» |

Проценты и приблизительные проценты модель возвращает, но текущий
рендер скрывает их в видимом содержимом. Подробности доступны в
`title` и `aria-label`: вероятность клика, базовый уровень, объём
данных или объяснение обучения.

Цветовые зоны считаются относительно персонального baseline, а не по
фиксированным порогам видимого процента. Логику зон и калибровки
следует оставлять за доменным слоем.

### Время публикации

Русское относительное время через `Intl.RelativeTimeFormat`;
точная локальная дата — в `title`. Обновление подписей раз в минуту.
Публикации возрастом от `0` до `30` минут включительно имеют жёлтую
дату. Будущие даты этим правилом не подсвечиваются.

### Плавающее управление — `.fab`

Группа `role="group"`, доступное название «Управление лентой».
Слева «Обновлено: …», справа refresh и settings. Длинная подпись
обрезается многоточием.

Refresh во время запроса disabled, иконка вращается; подпись времени
становится «в процессе». Автообновление не делает промежуточный
полный рендер, но статус и блокировка кнопки обновляются.

## Настройки

### Оболочка диалога

`.settings` содержит backdrop и `.settings__panel` с
`role="dialog"`, `aria-modal="true"` и названием
«Настройки ленты». Флаг открытия отражается в классе, `aria-hidden`
и `aria-expanded` кнопки входа.

Desktop: общий header «Настройки», слева навигация, справа активный
раздел. Mobile: сначала меню, затем выбранный раздел с кнопкой «Назад».
Кнопка закрытия присутствует в обоих случаях.

У каждого пункта навигации есть `aria-controls`, у активного —
`aria-current="true"`. Раздел — `role="region"`, связанный с
названием пункта; неактивные разделы скрываются через `hidden`.
Это навигационные кнопки, не реализованный ARIA tablist.

### Карточка группы подписок

`.settings__folder`:

- header с drag-handle, кнопкой раскрытия, названием и числом подписок;
- действия редактирования и удаления;
- раскрываемый список подписок;
- кнопка «Добавить подписку» / «Добавить первую подписку»;
- одна встроенная форма новой подписки, если она открыта для группы.

По умолчанию группы свёрнуты; раскрытие запоминается в памяти сессии.
В edit-режиме header заменяется полем названия, счётчиком и кнопками
«Сохранить» / «Отмена». Перетаскивание в этом header недоступно.

Drag-handle выключен, если колонка одна. При переносе исходная строка
полупрозрачна; отдельный preview неинтерактивен, скрыт от accessibility
дерева и перемещается через transform.

### Строка подписки

Обычный режим: название и hostname слева; звезда, редактирование,
удаление справа. Полный URL хранится в `title`.

Edit-режим: поля названия и URL, «Сохранить» / «Отмена».
Одновременно активно одно редактирование: группы либо подписки.

Избранность — переключатель `aria-pressed`; его доступная подпись
меняется между добавлением и удалением из избранного.

### Формы создания

Новая колонка открывается отдельным блоком под кнопкой создания.
После создания форма скрывается; фокус переводится к действию новой
группы.

Новая подписка открывается внутри выбранной группы, а не в отдельном
модальном окне. В текущем DOM один composer перемещается между
группами; для Svelte важен результат «одна активная форма», а не
буквальное перемещение DOM.

Состояния подписки: закрыто → заполнение → «Проверка…» →
успех либо inline-ошибка. Во время проверки отключены все контролы
формы, включая отмену, и кнопки добавления подписок в других группах.
`aria-busy` выставляется на форме.

### Разделы

| Раздел | Состав |
| --- | --- |
| Колонки и подписки | Создание, раскрытие групп, редактирование, избранность, удаление, перестановка |
| Поведение интерфейса | Три checkbox-опции; каждое изменение сохраняется сразу |
| Фильтр публикаций | Textarea, объяснение правил, явная кнопка «Сохранить» |
| Импорт и экспорт | Две отдельные action-карточки и системный выбор файла |
| Сбросить всё | Danger-кнопка внизу навигации, отдельно от разделов |

Сценарии, подтверждения и точные последствия действий описаны в
[UX-сценариях](ux-flows.md).
