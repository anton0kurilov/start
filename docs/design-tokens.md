# Визуальные основы и токены

[К оглавлению](README.md). Актуализировано 12 ноября 2026 года после
подключения Onest. Источник значений — [_tokens.scss](../src/styles/_tokens.scss),
подключённый первым в [base.scss](../src/styles/base.scss).

## Устройство системы

Примитивы задают ограниченные шкалы. Семантические токены описывают роль
цвета и поверхности; компонент выбирает роль, а не вводит похожий оттенок.
Ноль, проценты, viewport units и технические размеры границ не являются
шагами spacing-шкалы. Breakpoint остаются 1100 / 900 / 720px: CSS-переменные
не используются в media query. Размеры колонок и диалога — отдельные
layout-токены, а не дополнительные расстояния.

Старые --padding, --margin и --borderRadius оставлены как совместимые
алиасы на space5, space7 и radiusMd. Дробные множители этих алиасов для
получения промежуточных расстояний удалены. Safe-area по-прежнему
добавляется к отступу, где это необходимо.

в компонент не добавляется.

их до соседнего шага. Детали 5/9px сведены к 4/8px.

## Типографика

Основная гарнитура — Onest. Один локальный variable-файл WOFF2 (84 164 байта)
содержит полный набор символов исходного шрифта, включая кириллицу, латиницу,
₽ и №, и веса 100–900. Интерфейс использует 400 / 500 / 600.
Файл и SIL Open Font License лежат в `public/assets/fonts/`;
объявление — в [_fonts.scss](../src/styles/_fonts.scss), preload — в
[index.html](../index.html). Запросов к Google Fonts, CDN и локально
установленным гарнитурам нет. Системный стек остаётся резервным после Onest,
`font-display: swap` сохраняет видимость текста во время загрузки.

Размеры заданы в rem и масштабируются с настройками браузера. Пиксели
ниже — эквивалент при корневом размере 16px, не фиксированное требование.

| Токен | rem | Эквивалент | Роль |
| --- | --- | --- | --- |
| --fontSizeXs | 0.75 | 12px | Компактные индикаторы и бейджи |
| --fontSizeSm | 0.8125 | 13px | Источник, время, URL, метаданные и короткие пояснения |
| --fontSizeMd | 0.875 | 14px | Навигация, label, вторичный текст |
| --fontSizeBase | 1 | 16px | Кнопки, поля, заголовки публикаций |
| --fontSizeLg | 1.125 | 18px | Заголовок колонки |
| --fontSizeXl | 1.25 | 20px | Заголовок настроек mobile |
| --fontSize2xl | 1.5 | 24px | Заголовок настроек desktop |

Вес: --fontWeightRegular / Medium / Semibold = 400 / 500 / 600.
Межстрочный интервал: --lineHeightTight / Normal / Relaxed =
1.25 / 1.4 / 1.5. Все значения безразмерные; line-height не фиксируется
в px/rem. Tracking: --trackingTight = -0.015em только для заголовков от
24px, --trackingNormal и --trackingLabel = 0; --trackingCaps = 0.05em
для источников в верхнем регистре.

| Роль | Размер / вес / интерлиньяж | Tracking |
| --- | --- | --- |
| Заголовок публикации | 16px / 600 / 1.5 (24px) | 0 |
| Заголовок колонки | 18px / 600 / 1.4 (25.2px) | 0 |
| Источник | 13px / 500 / 1.4 (18.2px) | 0.05em, uppercase |
| Время, URL и метаданные | 13px / 400 / 1.4 (18.2px) | 0 |
| Пояснения в настройках | 14px / 400 / 1.5 (21px) | 0 |
| Короткие примечания | 13px / 400 / 1.5 (19.5px) | 0 |
| Заголовок настроек desktop | 24px / 600 / 1.25 (30px) | -0.015em |
| Заголовок настроек mobile | 20px / 600 / 1.4 (28px) | 0 |

Заголовки публикаций переносятся полностью, без line-clamp;
`text-wrap: pretty` улучшает последние строки, `overflow-wrap: anywhere`
удерживает длинные слова и ссылки в карточке. Короткие заголовки колонок
и настроек используют `text-wrap: balance`. Счётчики, время и числовые
индикаторы используют `tabular-nums`; текст сохраняет пропорциональные цифры.
Поля остаются 16px, включая mobile, чтобы iOS не увеличивала страницу при фокусе.

За основу взят навык
[better-typography](https://github.com/jakubkrehel/skills/blob/main/skills/better-typography/SKILL.md):
размер, вес и интерлиньяж выбираются по роли, длинные заголовки получают
достаточный межстрочный интервал, обычный текст не разряжается. Карточки —
узкие блоки интерфейса; рекомендации о строке 60–75 символов для длинной
статьи не используются как основание расширять колонки ленты.
[WCAG Text Spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)
требует сохранения содержимого при пользовательском увеличении интервалов,
а не обязательной разрядки всего интерфейса до 0.12em.

## Палитра

| Роль | Значение / токен |
| --- | --- |
| Фон | --colorBackground: чёрный |
| Поверхность | --colorSurface: #111 |
| Приподнятая поверхность | --colorSurfaceRaised: #202020 |
| Hover поверхности | --colorSurfaceHover: #303030 |
| Граница | --colorBorder: #262626 |
| Текст | --colorText: #e9e9e9 |
| Выраженный текст / hover primary | --colorTextStrong: #fff |
| Вторичный текст | --colorMuted: #c8c8c8 |
| Метаданные / прочитанное / фокус | --colorAccent: #919191 |
| Зелёный сигнал | --colorSignalHigh: #86efac |
| Жёлтый сигнал | --colorHighlight / --colorSignalMedium: #fde68a |
| Красный сигнал | --colorSignalLow / --colorDanger: #fca5a5 |
| Текст на primary | --colorOnPrimary: surface |

Жёлтый избранного, свежести и средней полезности использует один RGB.
Красный удаления, ошибки и низкой полезности тоже использует один RGB.
Прежние #f97373/#fca5a5, #facc15/#fde68a и разные RGB цветных подложек
объединены. Primary использует основной текстовый нейтральный цвет,
hover — белый, вместо самостоятельных #e5e5e5/#f2f2f2.

Поверхности намеренно имеют разные уровни: surface, raised и hover
выполняют разные роли. Небольшие различия вроде #1f1f1f/#202020 сведены
к одному raised. Opaque --colorToast: #201414 сохраняет читаемость ошибки
поверх содержимого; это специальная поверхность уведомления.

### Прозрачности и состояния

- Нейтральная заливка: --colorFillSubtle / Fill / FillHover = белый
  с alpha 0.02 / 0.04 / 0.08.
- Цветной слабый tint: --opacityTintSubtle = 0.04; обычный
  --opacityTint = 0.08; hover --opacityTintHover = 0.12.
- Цветные границы: --opacityBorderSubtle = 0.24,
  --opacityBorder = 0.48. Нейтральный hover: --colorBorderHover.
- Disabled: --opacityDisabled = 0.6; drag: --opacityDragging = 0.3.
- Стекло --colorGlass: чёрный / 0.24; backdrop --colorBackdrop:
  чёрный / 0.8. Отдельных почти чёрных RGB у них больше нет.

Каждая группа сигналов имеет текст, Border и Bg из одной базовой краски.
Подложки избранных и рекомендуемых карточек собираются на непрозрачном
чёрном основании: цвет не меняется из-за поверхности колонки.

## Геометрия, эффекты и слои

Иконки: --sizeIconXs/Sm/Md/Lg = 12/16/20/24px.
Компактные контролы: --sizeControlSm/Md/Lg/Touch = 24/32/36/44px.
--sizeControl для форм зависит от rem и line-height, при стандартном
размере даёт 44px. Минимальная высота header колонки и положение новых
материалов связаны через --heightColumnHeader.

Layout: --widthColumn = 360px, --widthColumnMin = 240px,
--widthOnboarding = 440px,
--widthSettings = 1040px, --widthSettingsCompact = 720px,
--widthSettingsNav = 240px, --heightSettingsMax = 860px.
Textarea/filter: --heightTextarea = 120px, --heightFilter = 180px.

Тени: --shadowNotice, --shadowFloating, --shadowDialog, --shadowDrag.
Blur: --blurSm = 8px, --blurMd = 12px. Рамка --borderWidth = 1px,
обводка фокуса --focusWidth = 2px; offset — space1.
Слои: --layerHeader/Notice/Drag/Floating/Dialog = 2/3/5/30/50.

## Движение

| Токен | Значение | Роль |
| --- | --- | --- |
| --durationFast | 160ms | Hover, focus, переход диалога |
| --durationNormal | 240ms | Появление уведомления |
| --durationSlow | 480ms | Вход FAB |
| --durationSpin | 800ms | Один оборот refresh |
| --easeStandard | ease | Переходы интерфейса |
| --easeLinear | linear | Непрерывное вращение |

--motionOffsetSm/Md = space4/space6, --motionScaleEnter = 0.98.
В режиме prefers-reduced-motion отключены переходы и анимации
основных контролов, FAB, уведомления, диалога и refresh. JS уже
использует мгновенный scroll-to-top в этом режиме.

## Правило расширения

Сначала использовать существующий токен. Для нового цвета проверить,
не является ли он ещё одной прозрачностью существующего RGB. Новый
шаг шкалы добавлять в _tokens.scss только с отдельной ролью и причиной.
Технические 1px для скрытых accessibility-элементов и геометрия CSS-галочки
не превращаются в публичные spacing-токены.
