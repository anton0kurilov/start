# Визуальные основы

[К оглавлению](README.md). Все значения ниже описывают текущий SCSS.
Имена существующих CSS-переменных сохранены, чтобы их можно было напрямую
сопоставить с реализацией.

## Цвет

Источник: [base.scss](../src/styles/base.scss).

### Основа

| Токен | Значение | Использование |
| --- | --- | --- |
| `--colorBackground` | `#000` | Фон приложения, непрозрачная подложка выделенных карточек |
| `--colorSurface` | `#111` | Настройки, поля, hover обычной карточки |
| `--colorBorder` | `#262626` | Основные границы, фон кнопки новых материалов |
| `--colorText` | `#e9e9e9` | Основной текст |
| `--colorMuted` | `rgba(200, 200, 200, 0.9)` | Вторичные подписи и сообщения |
| `--colorAccent` | `#919191` | Источник, время, прочитанный заголовок, фокус |
| `--colorDanger` | `#f97373` | Удаление и ошибки формы |

Название `colorAccent` не означает основной яркий брендовый цвет:
фактически это нейтральный серый.

| Токен | Значение |

| `--colorSignalHighRgb` | `134, 239, 172` |

| `--colorSignalMediumBorder` | `rgba(253, 230, 138, 0.45)` |
| `--colorSignalMediumBg` | `rgba(var(--colorHighlightRgb), 0.1)` |
| `--colorSignalLow` | `#fca5a5` |

| `--colorSignalLowBg` | `rgba(239, 68, 68, 0.1)` |
| `--colorSignalLearningBg` | `rgba(145, 145, 145, 0.1)` |

Семантика:

- жёлтый — избранный источник и свежая дата;
- зелёный — высокая полезность и колонка рекомендаций;
- светло-жёлтый — средняя полезность;
- красный — низкая полезность, отрицательная оценка или ошибка; различать
  их нужно по контексту и доступному названию;
- серый — обучение, метаданные и прочитанность.

Избранная карточка имеет жёлтую границу с alpha `0.24` и подложку
`0.035`, при hover/focus — `0.065`. В рекомендуемой колонке эти же
коэффициенты применяются к зелёному RGB. Фон собирается поверх
непрозрачного чёрного, поэтому оттенок карточки не зависит от фона колонки.

Для рекомендуемой колонки: граница `highRgb / 0.26`, фон
`highRgb / 0.035`, едва заметная внутренняя обводка.

### Локальные значения, пока не вынесенные в токены

| Элемент | Значения |
| --- | --- |
| Primary-кнопка | Фон и граница `#e5e5e5`, текст `#05170f`; hover `#f2f2f2` |
| Ghost hover | Фон `rgba(255,255,255,0.04)`, граница `rgba(233,233,233,0.28)` |
| Danger-кнопка | Красный фон alpha `0.08 → 0.2`, граница `0.35 → 0.6` |
| Backdrop настроек | `rgba(4,6,10,0.76)`, blur `8px` |
| Стекло FAB и заголовка колонки | `rgba(1,1,1,var(--fabGlassAlpha))`, blur `10px` |
| Ошибка над FAB | Фон `rgba(23,10,10,0.92)`, blur `10px` |
| Карточка настроек | Белый градиент alpha `0.03 → 0.015` поверх surface |

Предложение: при переносе выделять семантические токены постепенно, не
заменяя локальные значения приблизительно похожей палитрой UI-kit.

## Геометрия

| Токен | Значение | Роль |
| --- | --- | --- |
| `--padding` | `12px` | Базовый внутренний отступ и промежуток |
| `--margin` | `20px` | Расстояние между колонками |
| `--borderRadius` | `10px` | Базовый радиус |
| `--widthColumn` | `360px` | Колонка desktop; ширина FAB |
| `--fabGlassAlpha` | `0.22` | Прозрачность стеклянных поверхностей |
| `--safeAreaTop` | `env(safe-area-inset-top)` | Верхний системный отступ |
| `--safeAreaRight` | `env(safe-area-inset-right)` | Правый системный отступ |
| `--safeAreaBottom` | `env(safe-area-inset-bottom)` | Нижний системный отступ |
| `--safeAreaLeft` | `env(safe-area-inset-left)` | Левый системный отступ |
| `--settingsControlHeight` | `calc(1.25rem + 22px)` | Локальная высота контролов настроек |
| `--settingsOptionSpacing` | `14px` | Локальный отступ checkbox-строки |
| `--feedHighlightRgb` | `var(--colorHighlightRgb)` либо `var(--colorSignalHighRgb)` | Локальный оттенок выделенной карточки |
| `--fabSafeArea` | `120px` на mobile | Объявлен, но в SCSS не используется |

Часто встречаются локальные расстояния `4 / 6 / 8 / 10 / 12 / 14 / 16 /
20px`. Это наблюдаемые значения, не существующая строгая шкала из
единственного набора spacing-токенов.

Производные от `--padding`: `0.7 = 8.4px`, `0.85 = 10.2px`,
`0.9 = 10.8px`, `1.05 = 12.6px`, `1.1 = 13.2px`,
`1.15 = 13.8px`, `1.3 = 15.6px`, `1.4 = 16.8px`,
`1.5 = 18px`.

## Типографика

Системный стек: `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI',
Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue',
sans-serif`. Внешние шрифты не загружаются. Корневой размер не задан;
`rem` сохраняет зависимость от настроек браузера.

| Роль | Размер | Насыщенность / дополнительные свойства |
| --- | --- | --- |
| Название настроек desktop | `1.6rem` | tracking `-0.03em` |
| Название настроек mobile | `1.2rem` | Обрезка многоточием |
| Название раздела mobile | `1.05rem` | line-height `1.25`, перенос разрешён |
| Название колонки | `1.1rem` | line-height `1.2`, tracking `-0.02em` |
| Заголовок блока настроек | `1rem` | `600` |
| Заголовок публикации | `0.98rem` | `600`, line-height `1.3`, без line-clamp |
| Название группы в настройках | `0.95rem` | `600` |
| Название подписки | `0.9rem` | `600` |
| Обычная кнопка | `0.95rem` | `600` |
| Поле | `0.95rem`; в настройках `1rem` | В настройках line-height `1.25` |
| Подпись поля | `0.85rem` | muted, gap до поля `6px` |
| Пояснение | `0.8rem` | muted, обычно line-height `1.45` |
| URL / число подписок | `0.75rem` | muted |
| Время публикации | `0.72rem` | accent или recent |
| Источник | `0.7rem` | uppercase, tracking `0.12em` |
| Новые материалы | `0.68rem` | `600`, tracking `0.025em` |
| Индикатор полезности | `0.66rem` | tracking `0.02em` |

Длинный заголовок карточки переносится через `word-break: break-word`.
Названия и URL в настройках на desktop допускают перенос, на mobile
обрезаются многоточием; полное значение остаётся в `title`.

## Сетка и адаптивность

Все breakpoint-условия — `max-width`, граница включительно.

| Ширина | Лента | Настройки |
| --- | --- | --- |
| Более `1100px` | Колонки `360px`, gap `20px`, боковые отступы `16.8px` | Диалог шириной `min(1040px,96vw)` |
| `721–1100px` | `grid-auto-columns: minmax(240px,1fr)`; отступы `12px`, снизу `20px` | Две области, навигация `240px` |
| До `900px` | Правила ленты не меняются отдельно | Ширина диалога `min(720px,94vw)` |
| До `720px` | Колонка на всю ширину, gap `0`, без внешней рамки и радиуса | Меню разделов и экран раздела показываются по очереди |

Лента — горизонтальный CSS Grid с `grid-auto-flow: column`.
Desktop использует `scroll-snap-type: x proximity`; mobile —
`x mandatory` и `scroll-snap-stop: always`. Это не перенос колонок
в вертикальный список. У каждой колонки свой вертикальный скролл.

Высота приложения desktop — `100vh`; mobile использует `100svh`
с fallback `100vh`, body не прокручивается. Заголовок находится внутри
прокручиваемого содержимого колонки и имеет `position: sticky; top: 0`.
На mobile необходимо учитывать оба существующих scroll-контейнера:
колонку и её содержимое.

Диалог desktop: высота `min(88dvh,860px)` с fallback на `vh`.
На mobile он занимает доступную высоту за вычетом safe area и двух
отступов `12px`; есть отдельный фиксированный header и прокручиваемое
содержимое.

FAB desktop закреплён справа снизу с отступом `16.8px + safe area`.
Mobile: слева/справа `12px`, снизу `max(12px,safeAreaBottom)`,
ширина доступная. Полное перекрытие последней карточки FAB нужно
проверять отдельно: резерв `--fabSafeArea` сейчас не подключён.

## Слои, тени и движение

| Элемент | z-index / эффект |
| --- | --- |
| Sticky header колонки | `2` |
| Новые материалы | `3`; тень `0 5px 18px rgba(0,0,0,0.32)` |
| FAB | `30` |
| Настройки | `50` |
| Drag-preview | `5` внутри настроек; тень `0 8px 24px rgba(0,0,0,0.25)` |
| Диалог | Тень `0 30px 60px rgba(0,0,0,0.55)` |
| Ошибка FAB | Тень `0 12px 28px rgba(0,0,0,0.36)` |

| Движение | Текущее значение |
| --- | --- |
| Hover кнопок / опций / навигации | Обычно `0.2s ease` |
| Показ настроек | Opacity/visibility `0.2s ease`, transform `translateY(12px) scale(0.98) → none` |
| Появление FAB | `0.45s ease`, opacity и сдвиг вверх на `14px` |
| Появление ошибки FAB | `0.22s ease`, opacity и сдвиг на `8px` |
| Обновление | Вращение иконки `0.8s linear infinite` |
| Новые материалы hover | `0.18s ease` |
| Клик по заголовку / новым материалам | Smooth-scroll к началу |

`prefers-reduced-motion` сейчас учитывается только при программном
скролле к началу. Остальные анимации не имеют отдельного reduced-motion
режима — это открытая задача из [аудита](ui-audit.md).

Фокус: глобальная обводка `2px solid var(--colorAccent)`,
`outline-offset: 2px`. Иконки — inline SVG с `fill: currentColor`,
размер зависит от компонента; используются viewBox `24 × 24` и
`0 -960 960 960`. Внешнего icon font или общей библиотеки иконок нет.
