# Сценарии и поведение

[К оглавлению](README.md). Здесь описано текущее поведение.
Предложения по исправлениям находятся в [аудите](ui-audit.md).

## 1. Первый запуск

1. Из `localStorage` читаются папки, настройки, история и модель.
2. Привязываются события, настраиваются safe-area переменные.
3. Настройки закрываются, выбирается начальный раздел.
4. Запускается обновление; без подписок сетевого запроса нет.
5. При отсутствии папок виден общий empty state и плавающие действия.

У онбординга нет мастера, стартовых подписок и автоматического поиска RSS.
Путь к первой публикации: «Настройки» → «Колонки и подписки» →
«Новая колонка» → раскрыть группу → «Добавить первую подписку».

Настройки по умолчанию:

| Настройка | Значение |
| --- | --- |
| Автоматическая прочитанность при прокрутке | Выключена |
| Автообновление каждые 5 минут | Выключено |
| Колонка рекомендаций | Выключена |
| Фильтр заголовков | Пустой список |

Важное ограничение: при offline и наличии сохранённых подписок refresh
выходит раньше первого рендера. Начальное отображение локального
состояния нужно отделить от сети при переносе; см. [аудит](ui-audit.md).

## 2. Просмотр и открытие публикаций

- Обычная колонка объединяет публикации своих подписок и сортирует
  сначала новые. Видны первые `40`.
- Пользователь прокручивает колонки независимо; на mobile переходит
  между ними горизонтальным свайпом.
- Клик по источнику/заголовку открывает сайт в новой вкладке.
- Обычный клик и средняя кнопка мыши отмечают публикацию прочитанной
  и регистрируют открытие для модели.
- Клик по отрицательной оценке не открывает ссылку.
- Публикация без пригодной HTTP(S)-ссылки не открывается и не получает
  положительное событие от попытки открытия.
- Одинаковые `itemKey` в видимых копиях синхронно получают отметку
  прочитанности.

Ключ публикации сейчас берётся из ссылки, затем ID, затем комбинации
источника, заголовка и даты. Это пользовательская идентичность материала,
не его индекс в списке.

Управление браузером вроде открытия через контекстное меню не имеет
отдельной обработки в приложении. Не считать историю `clicked`
полным измерением всего чтения.

## 3. Прочитанность всей колонки

Кнопка в header действует на **отображаемые карточки**, не на все
публикации источников:

1. Если хотя бы одна непрочитана — отметить все отображаемые прочитанными.
2. Если все прочитаны — снять отметку со всех отображаемых.
3. Если карточек нет — кнопка выключена.

Отметка не удаляет карточки и не является кликом по статье.
Снятие прочитанности не стирает историю открытия для модели. Состояние
видимых копий обновляется, позиция прокрутки сохраняется.

## 4. Автоматическая прочитанность при прокрутке

Опция включается явно и сохраняется сразу.

- Учитывается только движение пользователя вниз.
- Прочитанной становится карточка, которая за это движение полностью
  пересекла верхнюю границу видимой области.
- Прокрутка вверх не выставляет отметки.
- Карточки, оказавшиеся выше экрана из-за вставки новых публикаций,
  не считаются прочитанными автоматически.
- При включении опции уже находящиеся выше экрана карточки не отмечаются.
- Программный возврат к началу и восстановление позиции после обновления
  подавляют автоматическую прочитанность.

Текущие защитные интервалы: до `1500ms` для перехода к началу
с досрочным снятием подавления при достижении верха; `250ms` после
восстановления content scroll. Это детали реализации, а контракт —
отсутствие ложных отметок.

## 5. Обновление лент

### Ручное

1. Нажать refresh либо поддерживаемое сочетание клавиш.
2. Если запрос уже идёт, используется тот же promise.
3. Если нет подписок, перерисовать состояние без запроса.
4. Если браузер сообщает offline, показать сообщение без запроса.
5. Скрыть прежнюю глобальную ошибку, выставить «в процессе»,
   заблокировать refresh и вращать иконку.
6. Сохранить текущую позицию, проверить доступность прокси и загрузить
   источники.
7. При ошибке отдельного источника оставить его предыдущие публикации
   в памяти.
8. После завершения перерисовать ленту с сохранением позиции,
   обновить время, разблокировать refresh.

Один запрос ограничен `12` секундами, включая чтение тела ответа.
Перед параллельной загрузкой выполняется отдельная проверка прокси.
Успешные и неуспешные источники обрабатываются независимо.

Сейчас `lastUpdated` обновляется и при полном провале загрузки.
Подпись «Обновлено» фактически может означать время последней попытки,
а не последнего успешного получения данных.

### Автоматическое

Опционально каждые `5` минут относительно `lastUpdated`.
Фоновая скрытая вкладка и offline откладывают обновление.
События focus, pageshow, visibilitychange и online повторно проверяют,
пора ли обновить ленты. Включение опции также проверяет просрочку.

Промежуточного полного рендера в начале автообновления нет.
Индикатор «в процессе» и блокировка refresh всё равно используются.
Отдельного сообщения об успешном обновлении нет.

### Ошибки

| Условие | Реакция |
| --- | --- |
| Браузер offline | «Нет подключения к интернету. Ленты не обновились.» |
| Ошиблись все подписки либо верхнеуровневое исключение | «Не удалось обновить ленты. Проверьте подключение к интернету.» |
| Часть подписок не обновилась, карточки есть | Сообщение в колонке «Ошибка обновления: <имена подписок>» |
| Карточек нет, есть ошибки источников | Ошибочное пустое состояние колонки |

Глобальная ошибка — `role="status"`, `aria-live="polite"`,
`aria-atomic="true"`. Она закрывается пользователем, новым запросом
либо событием online; автоматически по времени не исчезает.

Закрытие ошибки колонки действует на текущий набор ID, названий и
ошибок источников. После исчезновения этой ошибки запоминание очищается,
поэтому новая ошибка снова может быть показана.

## 6. Сохранение места и новые материалы

Перед обновлением сохраняются горизонтальный scroll ленты и состояние
каждой колонки по стабильному ключу:

- scrollTop колонки и её content;
- первая видимая карточка и её смещение;
- ключи прежних карточек и ещё не просмотренных новых материалов.

После изменения списка позиция восстанавливается по карточке-якорю.
Если якоря нет, используются прежние scroll offsets. При перестановке
папок состояния сопоставляются по ID; удалённая колонка не передаёт
свой scroll соседней.

Если пользователь был ниже начала и сверху появились новые
непрочитанные карточки, показывается «↑ Новые материалы».
Кнопка не содержит счётчика.

Она исчезает, когда:

- пользователь нажал её или header и дошёл до начала;
- соответствующие новые материалы вошли в видимую область;
- новые материалы отмечены прочитанными;
- они удалены из текущей выдачи.

Если пользователь уже наверху либо новые материалы находятся ниже
видимой области, кнопка не появляется.

## 7. Полезность и отрицательная обратная связь

Модель использует открытия, явные отрицательные оценки и показы.
Показ регистрируется после видимости не менее `60%` карточки в течение
`1200ms`; без IntersectionObserver этот учёт пропускается.
Один и тот же материал не должен создавать повторные события одного
типа только из-за ререндера или копии в другой колонке.

При недостатке данных показывается «обучается».
Проценты модели живут в доступном описании, а не в видимом badge.
Уже открытая публикация имеет состояние «посетил».

«Показывать меньше похожих публикаций»:

1. Записывает явное отрицательное событие и переобучает модель.
2. Делает кнопку активной, `aria-pressed="true"`.
3. Не меняет прежнюю прочитанность и не удаляет карточку на месте.
4. Не предоставляет обратного переключения: повторный клик не отменяет
   оценку.

Название модельного состояния «скрыл» сейчас расходится с фактическим
сохранением карточки. Это открытый UX-вопрос.

## 8. Настройки: вход, навигация, закрытие

Открытие — кнопкой в FAB. Закрытие — крестиком, backdrop или Escape.
При открытии блокируется прокрутка body.

Desktop показывает навигацию и активный раздел рядом; активный раздел
помнится в памяти. Mobile при каждом открытии начинает с меню.
Выбор раздела на mobile показывает его содержимое, меняет заголовок
и переводит фокус на «Назад».

«Назад» возвращает к меню, не закрывает настройки, и фокусирует
выбранный пункт. Вертикальная позиция каждого раздела запоминается
в памяти.

При закрытии активное редактирование названия/URL сбрасывается.
Если фокус был внутри настроек, он возвращается к кнопке открытия.
Desktop-вход не имеет явного перевода фокуса внутрь диалога и focus trap;
это ограничение текущей реализации.

## 9. Управление колонками и подписками

### Создать колонку

1. Открыть «Новая колонка»; фокус — в поле названия.
2. Ввести непустое название и отправить форму.
3. Колонка сохраняется локально, поле очищается, composer закрывается.
4. Фокус переходит к раскрытию новой группы, если она свёрнута,
   либо к добавлению подписки, если раскрыта.

«Отмена» очищает поле, скрывает composer и возвращает фокус к созданию.

### Добавить подписку

1. Раскрыть группу и нажать «Добавить подписку».
2. Внутри группы появляется одна активная форма с названием,
   RSS URL и пояснением целевой колонки.
3. Фокус — в поле названия.
4. После отправки: «Проверка…», блокировка контролов и других
   действий добавления.
5. Источник скачивается и проверяется на RSS/Atom. Пустая, но валидная
   RSS/Atom-лента допустима.
6. При успехе подписка сохраняется; composer очищается и закрывается;
   запускается обновление лент.
7. При ошибке значения остаются; появляется inline-ошибка,
   URL становится invalid и получает фокус.

Проверка выполняется до сохранения: добавить неподтверждённую
подписку offline сейчас нельзя. Удалённая во время проверки колонка
не получает подписку.

Черновик активного feed-composer и выделение текста сохраняются при
пересборке списка настроек. При переключении composer в другую группу
его поля могут переноситься вместе с ним: нельзя считать, что у каждой
группы уже есть независимый черновик.

### Редактировать

Одновременно редактируется одна группа или одна подписка.
Вход фокусирует и выделяет название. «Отмена» отменяет изменения
редактора. Для сохранения нужны непустые значения.

Изменение названия подписки не требует скачивания RSS; изменение
URL очищает прежний кэш этого источника в памяти и запускает refresh.
При редактировании нет такой же предварительной сетевой проверки,
как при добавлении; отклонённое сохранение не имеет отдельной
inline-ошибки.

### Избранное

Звезда в строке подписки переключает `isFavorite` и сохраняет его.
Карточки источника получают жёлтое выделение. Это не закладка статьи
и не ручное включение статьи в рекомендуемую колонку.

### Удалить

Удаление колонки удаляет её подписки, удаление подписки — сам источник.
В обоих случаях связанные публикации убираются из памяти и выполняется
обновление оставшихся лент. Подтверждения и Undo для этих двух действий
сейчас нет. История модели не является отдельным видимым архивом.

## 10. Переставить колонки

Перестановка выполняется в настройках за drag-handle; в ленте
перетаскивания header нет.

Pointer-сценарий:

1. Нажать handle основной кнопкой мыши / основным указателем.
2. Движение менее `5px` ещё не начинает drag.
3. После порога появляется preview; группа переставляется относительно
   середины соседних строк.
4. У края scroll-контейнера в зоне `48px` работает автопрокрутка.
5. Отпускание сохраняет новый порядок и объявляет новую позицию.
6. Ошибка сохранения возвращает исходный порядок и показывает текст ошибки.

Escape, pointercancel, потеря pointer capture, уход фокуса окна и закрытие
настроек отменяют drag. При Escape отменяется перенос, а не сразу весь
диалог.

Клавиатура: на handle ArrowUp / ArrowDown сразу перемещают колонку
на одну позицию, сохраняют порядок, возвращают фокус и прокручивают
строку в видимую область. Это не режим «поднять пробелом — отпустить
Enter». На границах списка действия нет.

## 11. Фильтр публикаций

В textarea вводится одна фраза на строку. Применение — только кнопкой
«Сохранить» / submit формы. Ввод не фильтрует ленту немедленно.

Нормализация убирает пробелы по краям, пустые строки и повторы без
учёта регистра. Заголовок скрывается при наличии любой буквальной
подстроки без учёта регистра. Это не регулярные выражения и не поиск
по тексту статьи.

Фильтр действует на обычные и рекомендуемую колонки. Он не является
отрицательной оценкой модели, не удаляет исходный материал из памяти.
После удаления фразы и сохранения ранее исключённые карточки могут
вернуться без повторной загрузки RSS.

Черновик textarea не перезаписывается обычным рендером, пока сохранённый
список фраз не изменился. Отдельного индикатора «есть несохранённые
изменения», кнопки отмены или подтверждения выхода нет.

## 12. Импорт, экспорт и сброс

### Экспорт

Без подтверждения скачивает JSON с именем
`start-feeds-YYYY-MM-DD-HH-mm.json` по локальному времени устройства.
Экспорт включает колонки, подписки и избранность, настройки, отметки,
события и артефакты модели. Тексты/список публикаций из памяти не
экспортируются.

### Импорт

1. Кнопка открывает системный выбор JSON-файла.
2. После выбора появляется native confirm:
   «Импорт заменит текущие колонки и потоки. Продолжить?»
3. Файл разбирается и нормализуется; успешный импорт заменяет состояние,
   очищает публикации в памяти и запускает refresh.
4. Выбор файла очищается, чтобы тот же файл можно было выбрать повторно.

Это замена, не объединение. При отмене текущее состояние сохраняется.
Повреждённый JSON и отклонённые данные сейчас завершаются без
пользовательского сообщения.

### Сброс

«Сбросить всё» открывает native confirm:
«Удалить все колонки, подписки и настройки приложения?»

При подтверждении очищаются локальное состояние, публикации и
редакторы; приложение возвращается к значениям по умолчанию.
При отмене ничего не меняется. Отдельного кастомного confirm-компонента
сейчас нет.

## Клавиатурные действия

| Контекст | Клавиша | Реакция |
| --- | --- | --- |
| Вне полей ввода | F5 без модификаторов | Обновить RSS, не перезагружать страницу |
| Вне полей ввода | Ctrl+R / Cmd+R без Alt/Shift | Обновить RSS |
| Поле / textarea / select / contenteditable | Те же сочетания | Приложение не перехватывает |
| Настройки / обычное состояние | Escape | Закрыть настройки, сбросив inline-edit |
| Активный drag | Escape | Отменить перемещение |
| Handle перестановки | ArrowUp / ArrowDown без Alt/Ctrl/Meta | Переместить на одну позицию |
| Нативные кнопки и формы | Стандартные Tab / Enter / Space | Сохранить семантику браузера |

Обработанные или повторяющиеся refresh-keydown не вызывают новые
действия. Дополнительных shortcuts для выбора колонок, like/dislike
или открытия настроек сейчас нет.
