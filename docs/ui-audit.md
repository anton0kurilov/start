# Аудит и приёмка переноса

[К оглавлению](README.md).

Статус этого файла: наблюдения по исходникам и план проверок.
Исходные наблюдения ниже сохранены как список задач. Результаты

## Подтверждённые ограничения

Исправленные пункты отмечены явно. Остальные требуют отдельного решения;
их семантика в этом переносе сохранена.

| Область                      | Наблюдение в текущем коде                                                                         | Что решить                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Доступность диалога          | Исправлено: фокус внутри, Tab ограничен, фон inert                                                | Проверено E2E                                                                     |
| Header колонки               | Исправлено: возврат к началу — семантическая кнопка                                               | Клавиатурный доступ сохранён                                                      |
| Touch targets                | Многие действия имеют размер `24–36px`, в том числе отрицательная оценка `24px`                   | Проверить и при необходимости увеличить hit area без изменения плотности карточек |
| Reduced motion               | После унификации токенов учитывается и в CSS, и при scroll-to-top                                 | Проверить на реальном устройстве                                                  |
| Импорт                       | Исправлено: сообщение рядом с выбором файла                                                       | При ошибке данные сохраняются                                                     |
| Редактирование URL           | Исправлено: inline-ошибка рядом с полями                                                          | Проверено E2E                                                                     |
| Удаление группы/подписки     | Немедленное, без подтверждения и Undo                                                             | Выбрать восстановление либо подтверждение                                         |
| Отрицательная оценка         | Карточка остаётся, отмены нет, model label говорит «скрыл»                                        | Уточнить смысл и обратимость                                                      |
| Моментальная обратная связь  | Исправлено: badge и кнопка обновляются сразу во всех копиях                                       | Проверено E2E                                                                     |
| Время обновления             | Записывается даже при полном сетевом провале                                                      | Разделить последнюю попытку и успешное обновление либо переименовать подпись      |
| Offline-старт                | Исправлено: локальный рендер до refresh                                                           | Публикации после перезапуска без сети ещё не кэшируются                           |
| Кэш публикаций               | Только память вкладки; Service Worker отсутствует                                                 | Отдельная задача на сохранение публикаций и автономный запуск                     |
| FAB и низ списка             | Не задан отдельный нижний резерв под FAB                                                          | Проверить доступность последней карточки и действий под FAB                       |
| Повторы                      | Рекомендуемая колонка объединяет источники без общей дедупликации                                 | Определить идентичность и правила повторов до выбора keyed-списков                |
| История браузера             | `:visited` и локальный `visited` одинаково окрашивают заголовок                                   | Решить, должен ли визуальный статус однозначно отражать локальное состояние       |
| Смена режима настроек        | CSS перестраивается на breakpoint; отдельного reconcile UI-состояния при resize нет               | Проверить переход mobile → desktop → mobile с открытым разделом                   |
| Фокус после изменения списка | Для отдельных сценариев есть ручное восстановление; общего правила после удаления/отмены edit нет | Определить предсказуемую следующую цель фокуса                                    |
| Несохранённые изменения      | Закрытие отменяет inline-edit без предупреждения; filter/composer имеют другую жизнь draft        | Явно описать политику сохранения и отмены                                         |
| Сохранение данных            | Многие вызовы `saveState` не показывают отказ хранилища в UI                                      | Согласовать сообщения о несохранённых изменениях                                  |

## Что требует проверки в браузере

Это риски/вопросы, а не доказанные дефекты:

- контраст маленьких серых подписей и цветных индикаторов на фактических
  полупрозрачных фонах;
- различимость high/medium/low без восприятия цвета: thumbs-up одинаковый,
  подробности находятся в доступной подписи/tooltip;
- доступ к `title`-подсказкам на touch-устройствах;
- сохранение видимого keyboard-focus у всех полей после сборки SCSS;
- доступность карточек под плавающими слоями и safe area;
- вложенный вертикальный scroll на iOS/Android, поведение клавиатуры
  в формах и устойчивость высоты при изменении браузерных панелей;
- длинные названия, длинные URL без пробелов, увеличенный шрифт;
- системные forced-colors и reduced-motion;
- восстановление горизонтальной позиции при включении рекомендаций;
- обновление вкладки во время ввода и изменение активного draft при
  импорте или сбросе.

## Контрольные размеры

Предложенный набор viewport для сравнений: `1440×900`, `1100×800`,
`900×800`, `721×800`, `720×800`, `390×844`, `320×740`.
Нужны обе стороны breakpoint, а не только один desktop и один mobile.
Числа — тестовые размеры, а не заявленные минимальные требования.

Отдельно: landscape, safe-area на реальном устройстве, zoom/увеличенный
системный шрифт, длинный список групп и несколько десятков карточек.

## Визуальный baseline

Перед реализацией Svelte сохранить эталонные изображения на
детерминированных тестовых данных:

- пустой первый запуск;
- обычные колонки с непрочитанными, прочитанными и свежими карточками;
- избранный источник и рекомендуемая колонка рядом;
- learning / high / medium / low / visited / dismissed;
- частичная ошибка, полный провал обновления и offline-сообщение;
- новые материалы выше текущего якоря;
- настройки desktop и mobile: меню и выбранный раздел;
- создание колонки, проверка подписки, inline-ошибка;
- редактирование подписки, filter-draft и drag-preview.

Даты и модельные результаты для сравнения фиксировать, иначе
относительное время и обучение создадут нерелевантные различия.
Использовать отдельный тестовый профиль; не заменять пользовательские
подписки ради демонстрационных состояний.

## Матрица функциональной приёмки

Матрица описывает ожидаемое поведение. Выполненные автоматические проверки
и ограничения приёмки перечислены в [журнале](svelte-migration.md).

| Проверка                             | Ожидаемый результат                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| Первый запуск без подписок           | Empty state и действия доступны, сетевого запроса нет                          |
| Reload с сохранёнными настройками    | Порядок, избранность, флаги и история восстановлены                            |
| Клик / средняя кнопка по статье      | Одна запись открытия, прочитанность во всех копиях, новая вкладка              |
| Некорректная ссылка                  | Нет перехода и ложного положительного события                                  |
| Кнопка прочитанности                 | Переключаются только отображаемые карточки; повторное действие снимает отметки |
| Auto-mark вниз                       | Отмечаются только карточки, пересёкшие верхнюю границу                         |
| Auto-mark вверх / программный scroll | Новых отметок нет                                                              |
| Вставка материалов сверху            | Видимая карточка остаётся на прежнем месте                                     |
| Новые материалы                      | Notice появляется только для непросмотренных поступлений сверху                |
| Повторный refresh во время запроса   | Нет второго параллельного обновления                                           |
| Частичная ошибка                     | Старые карточки остаются, ошибка локализована в колонке                        |
| Полная ошибка                        | Refresh разблокирован, глобальная ошибка доступна и закрывается                |
| Auto-refresh скрытой вкладки         | Нет лишнего запроса; при возвращении проверяется просрочка                     |
| Рекомендации                         | High отбирается без click-boost, дата имеет приоритет сортировки               |
| Избранность                          | Меняет оформление источника, не подменяет правила рекомендаций                 |
| Dismiss                              | Не открывает статью, не меняет прочитанность, не создаёт повторное событие     |
| Показ                                | Требует заданной видимости/времени, не дублируется ререндером                  |
| Создание подписки                    | Pending → успех/ошибка; draft не теряется, дубль submit блокируется            |
| Удаление группы во время проверки    | Ответ не сохраняет подписку в несуществующую группу                            |
| Edit названия / URL                  | Название меняется без refresh; URL запускает обновление                        |
| Перестановка pointer                 | Порядок сохраняется, scroll чтения не назначается чужой колонке                |
| Перестановка keyboard                | ArrowUp/Down, сохранение, фокус и status работают                              |
| Отмена drag / ошибка сохранения      | Возвращается исходный порядок                                                  |
| Фильтр до сохранения                 | Выдача не меняется; черновик переживает фоновый рендер                         |
| Фильтр после сохранения              | Буквальные подстроки без регистра; очистка возвращает кэшированные карточки    |
| Импорт / отказ подтверждения         | Замена только после подтверждения; отмена оставляет данные                     |
| Export → import                      | Сохраняются папки, настройки, избранность, история и модель                    |
| Сброс / отмена                       | Соответственно дефолтное состояние либо сохранение текущего                    |
| Mobile-настройки                     | Вход в меню, переход к разделу, «Назад», восстановление фокуса                 |
| Escape при drag                      | Отменяет перенос без непреднамеренного закрытия настроек                       |
| Размонтирование UI                   | Нет оставшихся timers, observers, listeners, preview и scroll-lock             |

Исправления из аудита должны иметь отдельное ожидаемое поведение.
Например, сообщение об ошибке импорта проверяется после его добавления,
а не объявляется уже существующим.

## Критерий готовности UI-переноса

1. Согласованные сценарии проходят на desktop и mobile.
2. Визуальные отличия либо отсутствуют, либо объяснены отдельным
   принятым улучшением.
3. Существующие поведенческие тесты сохранены/адаптированы и проходят.
4. Ввод, прокрутка и открытие статей не ждут серверного ответа.
5. Нет двойного учёта событий и утечек при размонтировании.
6. Подтверждённые ограничения не потерялись: исправлены либо оставлены
   явными задачами с описанным решением.
