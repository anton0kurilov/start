# UI/UX и дизайн-система Start.

Это описание интерфейса Start. После переезда 10 ноября приложение
работает на Svelte 5 + Vite; домен и формат данных сохранены.
Первичная инвентаризация — 19 октября 2026 года, базовый коммит:
`8e1dc78`. Визуальные основы актуализированы 10 ноября 2026 года: шкалы вынесены в
_tokens.scss. Значения из первой инвентаризации заменены новой системой.

## Продукт и основные задачи

Start. — персональный RSS/Atom-ридер с несколькими колонками. Пользователь
быстро просматривает заголовки, открывает интересные материалы на сайтах
источников и организует подписки по темам.

Основной экран отдан чтению. Управление источниками и редкие действия
собраны в одном окне настроек. Постоянный плавающий блок содержит время
обновления, обновление и вход в настройки.

Характер текущего интерфейса:

- тёмная монохромная основа, системный шрифт и высокая плотность информации;
- тонкие границы вместо выраженных теней у обычных карточек;
- цвет служит сигналом состояния или типа содержимого;
- на широком экране колонки стоят рядом, на телефоне переключаются свайпом;
- обновления должны сохранять место, на котором пользователь читает.

Это описание действующего визуального языка. Перенос на Svelte сам по себе
не предполагает редизайн, светлую тему или подключение стороннего UI-kit.

## Словарь

| В коде          | В интерфейсе               | Значение                                                                |
| --------------- | -------------------------- | ----------------------------------------------------------------------- |
| `folder`        | Колонка                    | Именованная группа подписок; определяет обычную колонку чтения          |
| `feed`          | Подписка; иногда «поток»   | RSS/Atom-источник внутри колонки                                        |
| `feed item`     | Публикация                 | Заголовок, источник, ссылка и дата                                      |
| `visited`       | Прочитано                  | Пользовательская отметка; также выставляется при открытии ссылки        |
| `clicked`       | Посетил                    | Факт открытия, используемый моделью; отличается от отметки прочитанного |
| `dismissed`     | Показывать меньше похожих  | Явный отрицательный сигнал модели; не удаляет карточку                  |
| `favorite feed` | Избранная подписка         | Звезда у источника и жёлтое выделение его карточек                      |
| `recommended`   | Рекомендуемое              | Дополнительная колонка публикаций с высокой модельной оценкой           |
| `impression`    | Нет отдельного элемента UI | Учёт показа публикации для обучения модели                              |

Избранное и рекомендуемое — разные понятия. Прочитанность, открытие,
отрицательная оценка и исключение фильтром тоже не взаимозаменяемы.

## Карта интерфейса

```text
Приложение
├── Лента колонок
│   ├── Рекомендуемое — опционально, всегда перед обычными колонками
│   └── Колонка × N
│       ├── Заголовок + переключение прочитанности
│       ├── Кнопка «↑ Новые материалы» поверх содержимого
│       ├── Сообщение об ошибке источников — при наличии карточек
│       └── Карточки / пустое состояние
├── Плавающее управление
│   ├── Обновлено: относительное время
│   ├── Обновить
│   ├── Настройки
│   └── Сообщение об ошибке обновления
└── Настройки — модальное окно
    ├── Колонки и подписки
    ├── Поведение интерфейса
    ├── Фильтр публикаций
    ├── Импорт и экспорт
    ├── Синхронизация
    └── Сбросить всё
```

## Границы текущего продукта

Настройки, подписки, отметки, история и очередь изменений сохраняются в
IndexedDB. При настроенном Supabase пользователь подключает профиль по фразе
из 12 слов. Обучение рекомендаций остаётся в браузере; действия синхронизируются.
Загруженные публикации находятся в памяти вкладки, постоянного кэша публикаций нет.
Наличие web manifest не является реализованным автономным запуском:
Service Worker в текущих исходниках отсутствует.

Порядок настройки общего облачного проекта и текущие ограничения описаны в
[инструкции Supabase](../supabase/README.md).
