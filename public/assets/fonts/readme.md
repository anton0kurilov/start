# Onest

`onest-variable.woff2` is a local, full-character-set conversion of
`Onest[wght].ttf` from https://github.com/google/fonts/tree/main/ofl/onest,
downloaded November 12, 2026. The upstream project is
https://github.com/simpals/onest.

Converted with FontTools 4.68.0 and Brotli 1.2.1, without subsetting or changing
the font's outlines or variation axes. The 100–900 weight range, all 780 mapped
characters, and the `tnum` OpenType feature are preserved. The resulting file is
84,164 bytes. The application uses weights 400, 500 and 600.

The font is distributed under SIL Open Font License 1.1; see
`onest-license.txt`. It is served from the same origin as the app, with no
external font requests.
